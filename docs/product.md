# 01 · 产品定位

## 🎯 一句话

> 输入文字描述，自动生成 Manim 风格的算法/数学动画视频。

## 😩 解决什么问题

| 痛点 | 现状 | 我们的解法 |
|---|---|---|
| 教学视频制作门槛高 | 要会 Manim + Python | 自然语言描述即可 |
| 录屏/手写板效率低 | 重复劳动、不可复用 | 一次 prompt，永久保存 |
| 不会 Manim 又想要精美动画 | 找外包/自学 | 零门槛，即时出片 |

## 👥 目标用户

### 🎯 P0 — MVP 核心用户
**算法/数据结构教学场景**
- **算法博主**（B 站、YouTube、抖音）—— 选题快、出片快
- **计算机/数学老师** —— 备课效率提升
- **求职/面试者** —— 讲解算法题的视频

### 🌱 P1 — 下一波扩展
- 自媒体科普作者（数学/物理/经济）
- 科研人员（论文/汇报配图）
- K12 学生（作业展示、错题讲解）

## 🆚 竞品对比

| 方案 | 优点 | 缺点 | 我们 |
|---|---|---|---|
| 录屏讲解 | 真实感 | 不精美、效率低 | 视觉碾压 |
| PPT 动画 | 上手快 | 呆板、不够流畅 | 流畅度碾压 |
| 自己写 Manim | 可控、专业 | 学习成本极高（>1 周） | **零门槛** |
| 找外包 (Fiverr/猪八戒) | 省事 | 贵 ($50/分钟起)、慢 (1-3天) | 几秒出片、价格低 |
| Runway / Pika (AI 视频) | 通用 | 不能精确表达算法步骤 | **算法可读性碾压** |

## ✨ 核心价值主张

> **"把 Manim 的 3Blue1Brown 风格，下放到每一个会打字的人。"**

## 🎨 品牌调性

- **视觉**：极简、专业、技术感
- **配色**：深色背景 + 蓝色高亮（致敬 3Blue1Brown）
- **Logo 方向**：发光的画布 / 流动的代码线条
- **Slogan 候选**：
  - "From idea to motion"
  - "Animate your algorithm"
  - "AI + Manim = Magic"

## 🔭 长期愿景

1. **v1.0** — 跑通 Web + 算法可视化（当前）
2. **v1.x** — 扩展算法谱与场景广度（数学 / 物理 / 流程图等）
3. **v2.0** — 协作编辑 + 模板市场 + 社区

## 📦 需求基线（v0.1 对齐稿）

> 本节是经讨论收敛后的需求规格，作为后续设计与实现的输入基线。
> 与上方历史段落冲突时，**以本节为准**。

### 🎯 一句话（共识稿）

输入关于算法/数学概念的自然语言描述（含可选的伪代码 / LaTeX 公式 / 截图），在合理时间内返回一段 3Blue1Brown 风格的可视化视频，并允许用户在生成后查看与调整代码、再渲染。

### 📥 输入边界
支持形式（可组合）：
- 自然语言描述（核心输入）
- 伪代码片段
- LaTeX 数学公式
- 截图（题目截图 / 参考动画截图 等）

**v1.0 单次输入上限**：prompt ≤ **500 字**、截图 ≤ **3 张**。超长时前端 warn，由用户决定是否继续。

### ⏱ 生成时长分档（参考目标，不写死）
| 档位 | 大致目标时长 | 典型场景 |
|---|---|---|
| 短 | ~30s | 简单数据结构、单步操作 |
| 中 | ~60s | 排序 / 搜索类算法 |
| 长 | ~2-3 分钟 | 复杂树 / 图算法 |

### 🎨 输出质量分档
| 档位 | 标准 | 适用场景 |
|---|---|---|
| 可讲解 | 视觉清晰、逻辑正确 | 自查 / 同事评审 |
| 可分享 | 风格统一、无明显瑕疵 | 公众号 / 博客文章 |
| 可发布 | 专业级、可直接上线 | 教学课程 / 视频平台 |

### 🎭 风格（v0.1 = 1 种默认 + 预留扩展）
| 风格 ID | 名称 | v0.1 状态 |
|---|---|---|
| `3b1b` | 3Blue1Brown | ✅ 默认交付 |
| `minimal` | 极简黑白 | 🚧 枚举预留 |
| `academic` | 学术配图风 | 🚧 枚举预留 |

- 风格以 `BaseStyle` 抽象承载；v0.5+ 可继续扩展（卡通风 / 商业风 等）
- v0.1 只实装 `3b1b`，其余在配置面与枚举上预留位置

### 🔁 失败与迭代体验（合并原 #5、#6；细节对应 v1.0 节）
- **正常路径**：渲染完成后，UI 展示视频 + **始终展示生成的代码**
- **失败路径**：自动重试 1-2 次（细节见 v1.0 节）；仍失败时贴出已生成代码 + 错误信息，让用户改完再提交
- 用户可以：
  - 直接修改代码（参数 / 注释 / 颜色 / 速度）
  - 或修改 prompt 触发重新生成
- 一键「重新渲染」

## 🎯 v1.0 开发目标

- **范围**：可用为先，跑通页面 + 完整流程
- **部署形态**：本地运行（不做公网部署）
- **用户概念**：**保留轻量 `user` 抽象，仅用于关联会话与历史记录**，不做登录 / 认证 / 付费
- **数据落地**：会话 / 历史 / 偏好都挂在 user 维度下，方便后续 v1.x 扩展（账号、协作、跨设备等）
- **历史范围**：**完整历史 + 标签 / 收藏** —— 可以攒下"作品集"
- **最小靶子**：3 个算法 —— 冒泡排序 + 二分查找 + 图的 BFS（覆盖面最广，跨线性 / 查找 / 图）；其余算法后续陆续补
- **产物规格**：mp4 + 可下载工程代码（与"失败/迭代体验"配套，让用户拿到代码后可续改）
- **多语言**：v1.0 UI 中英双语可切换；接受中 / 英 prompt
- **失败行为**：自动重试 1-2 次，仍失败则贴出已生成代码 + 错误，让用户手改后重新提交
- **并行数**：串行 1 个任务；多任务自动排队
- **输入长度**：单次 prompt ≤ **500 字**、截图 ≤ **3 张**
- **偏好**：v1.0 不单独设置页；生成时手动选风格 / 语言 / 质量
- **历史保留**：默认 **3 个月**；用户可手动清理（"清空全部" 按钮）
- **算法正确性**：排序 / 查找类 100% 严格；树 / 图类可视觉近似（流程可读即可）
- **错误文案**：中英双语（与 UI 语言切换同步）
- **中断行为**：进程被杀后静默丢失；UI 仍可看到"已完成 / 未完成"状态
- **内置模板**：分类下拉（排序 / 查找 / 树 / 图）
- **新手引导**：v1.0 不提供 onboarding（UI 自解释）
- **进度展示**：**百分比 + 节点名**（"正在生成代码 / 正在校验 / 正在渲染"）
- **视频规格**：默认 **720p / 30fps / H.264**
- **风格切换**：v1.0 UI 可切 3 种风格（与"风格枚举"一致）
- **收藏 / 标签**：v1.0 不做（历史按时间轴展示，不依赖标签 / 收藏检索）
- **反馈机制**：v1.0 不提供反馈入口
- **意图**：保留"作品 / 教学资料"的连续性，但不强制加账号门槛

## 🎯 v1.0 战略与方向（共识稿）

> 把 v1.0 的"为什么做 / 靠什么赢 / 怕什么 / 下一步去哪"四件事钉下来。

### 👥 主攻人群
**不差异化，三类人都拉齐**：
- 算法博主（B站 / YouTube / 抖音）
- 计算机 / 数学老师
- 算法面试者 / LeetCode 微信群

v1.0 的所有体验不偏向任何一类，但"杀手特性 / 杀手质量"以"三者都能用"为底线。

### 💎 杀手特性：可读写代码
v1.0 与 Runway / Pika / 录屏 / 外包 的最大差异点 —— **生成的代码用户可以续改**（不是黑盒视频）。

这条贯穿整个产品：
- 失败时贴出代码让用户改
- 成功时 UI 永远展示代码
- 一键「重新渲染」用修改后的代码
- 产物规格里有"工程代码"副产品

### ⚠️ 主要风险：算法表达不精确
最大风险**不是**渲染失败 / 速度慢，而是 **动画看不懂 / 算法讲不清**。
- 缓解：算法分类对待（排序 / 查找 100% 严格；树 / 图可视觉近似）
- 缓解：few-shot 库与基准 prompt 优先保证"算法可读性"
- 缓解：v1.x 引入 reviewer / 自检

### 🔭 v1.x 衔接：算法 / 场景广度
v1.0 跑通后的下一阶段重头戏是 **扩展算法谱与场景**：
- 加数学 / 物理 / 流程图等更多类别
- 加 P1 用户场景（科普 / 科研 / K12）
- 加更多 P0 算法（v1.0 = 3 个靶子）
